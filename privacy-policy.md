# NellieBot privacy policy

## Bot overview

Nellie is a multi-purpose Discord bot focused on server management, automated moderation and utility features.
It helps server administrators maintain safety and structure by automating moderation actions (like anti-spam and auto-muting),
providing customisable utility commands (such as custom event commands). It is currently fairly limited in functionality,
and primarily performs in-Discord logging of user events and automated anti-spam tasks.

The bot's source code is available in this repository.

## Stored personal data
At present, the bot **does not** store any personal information regarding a Discord user.
There are database tables that were constructed for this purpose, but they have not been completed.

Upon completion, the bot will store warnings and bans given to users.
It will store Discord user IDs alongside notes written by administrators regarding the warning or ban.
It will not store any other identifiable information.

## Data retention
* User IDs tied to warnings and warning notes are stored until the warning is deleted
